> {{ site.Params.description }}

Popcorn asks each configured assistant every buyer question on two tracks: search, where it must search the web first, and recall, with no tools. It grades each answer recommended, mentioned or absent, and ends every run with a ranked list of fixes: the page to create or change, what it must say, and the prompts it should flip. It is MIT licensed and self-hosted (one container with SQLite, on Docker, Kubernetes or an exe.dev VM), with a web UI, CLI, JSON API and MCP server. Source: {{ site.Params.github }}
