Popcorn: an open-source, self-hosted AI visibility tracker

Popcorn is an open-source (MIT), self-hosted AI visibility tracker, and an alternative to Profound, Peec AI and Ahrefs Brand Radar. It asks Claude and OpenAI models your buyers' questions, grades whether each answer recommends your brand, merely mentions it, or leaves it out, and builds a ranked list of fixes.

Get started Source on GitHub

MIT licensed, one Docker container, code at github.com/metcalfc/popcorn. Your prompts live in your own git repo.

Not affiliated with Bad Popcorn (badpopcorn.ai), Popcorn AI (trypopcorn.ai), popcorn.ai, popcorn.co or Reclaim Protocol's popcorn-oss.

How it works

  1. Your buyers' questions

    Prompt sets are TOML files in a config repo you own, one per category of buyer question, written the way someone who has never heard of you would type them. Changes go through pull requests.

  2. Two tracks, every assistant

    Each configured assistant answers every prompt on search, where it must search the web first, and recall, with no tools. You see both what the web says today and what the model already believes.

  3. Graded answers

    A second Claude call grades each answer recommended, mentioned or absent, with your position, the top pick, every product named, the objections raised, and why you weren't #1.

  4. Share of voice and rankings

    Each run shows rates per assistant and track with 95% intervals, and share of voice. Rankings follow your place day by day, and carry on through reworded, added and removed prompts.

  5. A ranked fix list

    Each run ends with Fix these first: the exact page to create or change, what it must say, the prompts it would flip, an effort estimate, and which of your sites it belongs on, with its owner.

Who it's for

The people who own how a product is described: product marketing, docs, the blog and the website. Popcorn is for teams who want to know whether AI assistants recommend their product when buyers ask, which pages shape those answers, and what to change first. Every search, result URL and citation behind an answer is kept, so you can see which third-party pages the assistants lean on and which of your own sites they never reach.

Open source, on your own infrastructure

  • MIT licensed. Read it, run it, change it.
  • Self-hosted. One container with a SQLite database, on a Docker host, Kubernetes (Helm chart) or an exe.dev VM.
  • Your config in your git repo. The brand, assistants, budget, schedule and prompt sets live in a config repo you can keep private. popcorn plan shows what a change does to your trends before you merge it.
  • A daily budget. Every API call reserves against budget.daily_usd before it goes out. Prompts and answers go only to the model providers you configure.
  • Web UI, CLI, JSON API and MCP server, so Claude Code or any MCP client can start runs and read results.

Get started

A fresh checkout runs as-is against an example config that measures Popcorn itself. You need Go and an Anthropic API key.

cp .env.example .env              # then fill in ANTHROPIC_API_KEY
go run ./cmd/popcorn serve        # the example, at http://127.0.0.1:3000

Read Getting started, then start your own config repo from the template.
