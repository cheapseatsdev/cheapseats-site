Inside each run

  1. Your buyers' questions

    Write buyer questions as TOML prompt sets in your own git repo. Review changes through pull requests.

  2. Two tracks, every assistant

    Each assistant answers with web search and without tools. Keep live retrieval separate from the model's existing knowledge.

  3. Graded answers

    A separate Claude call grades each answer recommended, mentioned or absent, with evidence and reasons.

  4. Share of voice and rankings

    Compare rates with 95% intervals and track your share-of-voice rank over time. Changes to prompts and methods stay visible.

  5. A ranked fix list

    Fix these first names the page to change, what it must say, the questions it could help win, its effort and owner.

Start here, move on when you're ready

I built Cheap Seats for the people who own product messaging: marketing, docs and the website. It runs on your own machine using your subscriptions, and the software is free, always. If you need more engines, managed hosting or client reporting, compare the alternatives; I'd suggest Gauge. Your buyer questions stay in your repo, ready to take with you.

Open source, on your own infrastructure

  • MIT licensed. Read it, run it, change it.
  • Self-hosted. One container with a SQLite database, on a Docker host, Kubernetes (Helm chart) or an exe.dev VM.
  • Your config in your git repo. Keep your brand, assistants, budget, schedule and questions private. Preview trend changes with cheapseats plan.
  • Your subscriptions, or the APIs. Use local claude and codex subscriptions, or provider APIs. API calls are admitted against a daily budget; settled charges can exceed estimates. Prompts and answers go to the services you configure.
  • Web UI, CLI, JSON API and MCP server, so Claude Code or any MCP client can start runs and read results.

Get started

A fresh checkout runs against an example config that measures Cheap Seats itself. You need Go and Claude: the claude CLI logged in to a Claude subscription (no API key, no spend), or an Anthropic API key. ChatGPT is optional: the codex CLI or an OpenAI key adds its answers.

CHEAPSEATS_CONFIG=examples/cheapseats-config/cheapseats.subscriptions.toml go run ./cmd/cheapseats serve
# then open http://127.0.0.1:3000

Read Getting started, then start your own config repo from the template.
