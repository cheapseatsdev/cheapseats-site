## Start here

Cheap Seats asks your buyers' questions, grades recommendation versus mention, and ranks page fixes for your own repo. Inspired by Gauge, it's free MIT-licensed software you run yourself, with no hosted tier.

Claude is required, through a subscription or an API key; OpenAI is optional, through Codex or an API key. Locally, an installed Claude Code subscription can cover the model calls. Hosting and API usage depend on your setup; container images have no subscription CLIs. See [cost and budget](/docs/cost-and-budget/).

## If you grow out of it

Look at hosted tools when you need more engines, consumer-app answers, country-specific runs, team workflows or enterprise procurement support. Cheap Seats asks only Claude and OpenAI models directly ([engine coverage](/docs/engines/)); you maintain the instance.

Your questions stay yours: copy the prompt text from TOML in your repo into the next tool. Each comparison explains its import path and prompt limits.
